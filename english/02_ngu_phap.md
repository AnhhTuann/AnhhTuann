## 1. Các Thì Trong Tiếng Anh

### Thì Hiện Tại Đơn (Simple Present)
```
CẤU TRÚC:
(+) S + V(s/es)              → She works at Google.
(-) S + don't/doesn't + V    → He doesn't like coffee.
(?) Do/Does + S + V?         → Do you study English?

DÙNG KHI:
✓ Thói quen: "I drink coffee every morning."
✓ Sự thật:   "The sun rises in the east."
✓ Lịch trình:"The train leaves at 8 AM."

SIGNAL WORDS: always, usually, often, sometimes, never,
              every day/week, on Mondays...
```

### Thì Hiện Tại Tiếp Diễn (Present Continuous)
```
CẤU TRÚC:
(+) S + am/is/are + V-ing    → I am studying now.
(-) S + am/is/are + not + V-ing
(?) Am/Is/Are + S + V-ing?

DÙNG KHI:
✓ Đang xảy ra ngay lúc nói: "She is typing an email."
✓ Xung quanh hiện tại:      "I'm reading a book this week."
✓ Kế hoạch tương lai:       "We are meeting tomorrow."

⚠️ KHÔNG dùng V-ING với:
know, like, love, hate, want, need, believe, understand, remember, forget
```

### Thì Quá Khứ Đơn (Simple Past)
```
CẤU TRÚC:
(+) S + V2/V-ed           → He worked yesterday.
(-) S + didn't + V(inf)   → She didn't come.
(?) Did + S + V(inf)?     → Did you see it?

ĐỘNG TỪ BẤT QUY TẮC QUAN TRỌNG:
go → went       come → came      see → saw
have → had      do → did         make → made
get → got       give → gave      take → took
know → knew     think → thought  say → said
find → found    leave → left     feel → felt
become → became begin → began    buy → bought

SIGNAL WORDS: yesterday, last week/month/year, ago, in 2020...
```

### Thì Hiện Tại Hoàn Thành (Present Perfect)
```
CẤU TRÚC:
(+) S + have/has + V3     → I have finished my work.
(-) S + haven't/hasn't + V3
(?) Have/Has + S + V3?

DÙNG KHI:
✓ Ảnh hưởng đến hiện tại: "I have lost my keys." (chưa tìm được)
✓ Kinh nghiệm:             "I have been to Japan."
✓ Vừa xong:                "She has just sent the email."
✓ Từ quá khứ → nay:       "I have worked here for 5 years."

SIGNAL WORDS: just, already, yet, ever, never, recently,
              for, since, so far, up to now...

⚠️ So sánh:
"I ate pizza."       → Quá khứ cụ thể (không liên quan hiện tại)
"I have eaten pizza." → Kinh nghiệm (liên quan hiện tại)
```

### Thì Tương Lai (Future)
```
WILL → Quyết định tức thì, dự đoán, lời hứa:
"I will help you." / "It will rain tomorrow."

BE GOING TO → Kế hoạch, dự định, bằng chứng rõ:
"I am going to study abroad next year."
"Look at those clouds — it's going to rain!"

PRESENT CONTINUOUS → Kế hoạch cụ thể đã sắp xếp:
"I'm meeting John at 3 PM tomorrow."

PRESENT SIMPLE → Lịch trình cố định:
"The flight departs at 6 AM."
```

## 2. Câu Điều Kiện (Conditionals)

```
TYPE 0 — Sự thật hiển nhiên:
If + Simple Present, Simple Present
"If you heat water to 100°C, it boils."

TYPE 1 — Có thể xảy ra (tương lai):
If + Simple Present, will + V
"If it rains, I will stay home."

TYPE 2 — Giả định hiện tại/tương lai:
If + Simple Past, would + V
"If I had more time, I would learn guitar."

TYPE 3 — Quá khứ không thể đổi:
If + Past Perfect, would have + V3
"If I had studied harder, I would have passed the exam."

MIXED — Quá khứ ảnh hưởng hiện tại:
If + Past Perfect, would + V
"If I had chosen CS, I would be a developer now."
```

## 3. Câu Bị Động (Passive Voice)

```
CẤU TRÚC: Object + be + V3 (+ by + Agent)

Active:  "The team fixed the bug."
Passive: "The bug was fixed (by the team)."

CÁC THÌ BỊ ĐỘNG:
Present Simple:    The code is reviewed daily.
Past Simple:       The bug was fixed yesterday.
Present Perfect:   The feature has been deployed.
Future Simple:     The app will be launched next week.
Present Cont.:     The issue is being investigated.

DÙNG KHI:
✓ Không biết / không cần nêu chủ thể
✓ Nhấn mạnh vào đối tượng bị tác động
✓ Văn phong trang trọng, khoa học
```

## 4. Câu Quan Hệ (Relative Clauses)

```
WHO    → người:    "The developer who built this app is amazing."
WHICH  → vật:     "The tool which I use is VSCode."
THAT   → người/vật:"The project that we finished was successful."
WHERE  → nơi:     "This is the office where I work."
WHEN   → thời gian:"I remember the day when I got my first job."
WHOSE  → sở hữu:  "The colleague whose code I reviewed is talented."

DEFINING (không dấu phẩy) → xác định cụ thể:
"The car that I bought is red."

NON-DEFINING (có dấu phẩy) → thông tin thêm:
"My car, which is red, needs repair."
```

## 5. Modal Verbs

| Modal | Cách dùng | Ví dụ |
|---|---|---|
| **can** | Khả năng hiện tại | "I can code in React." |
| **could** | Khả năng quá khứ / lịch sự | "Could you help me?" |
| **will** | Tương lai / quyết định | "I will fix this bug." |
| **would** | Điều kiện / lịch sự | "Would you like some help?" |
| **should** | Lời khuyên | "You should refactor this." |
| **must** | Bắt buộc / chắc chắn | "You must submit by Friday." |
| **have to** | Bắt buộc từ bên ngoài | "I have to attend the meeting." |
| **may** | Khả năng / xin phép | "May I ask a question?" |
| **might** | Khả năng nhỏ | "It might rain later." |
| **need to** | Cần thiết | "We need to deploy this now." |

## 6. Giới Từ (Prepositions)

```
THỜI GIAN:
at  → giờ cụ thể:     at 9 AM, at noon, at midnight
on  → ngày:           on Monday, on July 22
in  → tháng/năm/mùa: in July, in 2024, in summer, in the morning

NƠI CHỐN:
at  → điểm cụ thể: at school, at the office, at home
on  → bề mặt:      on the table, on the screen
in  → bên trong:   in the room, in Vietnam

THƯỜNG GẶP KHÁC:
for   → "I've worked here for 3 years."
since → "I've been coding since 2019."
by    → "Submit by Friday." / "Built by Google."
with  → "I work with React."
about → "Tell me about your project."
```
