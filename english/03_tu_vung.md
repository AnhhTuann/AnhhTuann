## 2. Chiến Lược Học Từ Mới — FRAMING

Mỗi khi gặp từ mới, áp dụng 5 bước:

```
1. Form (Hình thức):    Phát âm + Spelling
2. Meaning (Nghĩa):     Nghĩa trong ngữ cảnh này
3. Grammar (Từ loại):   Danh từ? Động từ? Tính từ?
4. Collocation (Cụm):   Đi với từ nào thường nhất?
5. Example (Ví dụ):     Tự đặt 1 câu với từ đó
```

**Ví dụ áp dụng FRAMING với từ "deadline":**
```
1. Form:        /ˈdedlaɪn/ — d-e-a-d-l-i-n-e
2. Meaning:     Hạn chót cần hoàn thành công việc
3. Grammar:     Danh từ (noun)
4. Collocation: meet a deadline, miss a deadline, tight deadline
5. Example:     "We need to meet the deadline by Friday."
```

## 3. Từ Vựng IT Chuyên Ngành

### Frontend Development
```
GIAO DIỆN:
layout, viewport, responsive, breakpoint, grid, flexbox,
component, widget, modal, tooltip, dropdown, sidebar,
navbar, footer, hero section, carousel, accordion

HIỆU NĂNG:
performance, optimization, lazy loading, code splitting,
bundling, minification, caching, compression, rendering,
First Contentful Paint (FCP), Largest Contentful Paint (LCP)

LẬP TRÌNH:
variable, function, method, class, object, array, loop,
condition, callback, promise, async/await, event listener,
API, endpoint, request, response, payload, error handling
```

### Câu Hay Dùng Trong Code Review
```
"This looks good to me."
→ Trông ổn / Approved.

"Could you explain why you chose this approach?"
→ Giải thích lý do chọn cách này?

"This might cause a performance issue."
→ Cái này có thể gây vấn đề hiệu năng.

"Consider using X instead of Y here."
→ Cân nhắc dùng X thay cho Y.

"Nice catch!"
→ Phát hiện tốt!

"This is blocking the release."
→ Cái này đang chặn không cho release được.

"Let's discuss this in the next sprint."
→ Để bàn ở sprint sau.

"I'll raise a ticket for this."
→ Tôi sẽ tạo ticket cho vấn đề này.
```

## 4. Cách Dùng Anki Hiệu Quả

**Cài đặt Anki:**
1. Tải [Anki](https://apps.ankiweb.net/) miễn phí
2. Tải deck tiếng Anh: tìm "English Frequency 3000" trên AnkiWeb
3. Học 10–20 thẻ mới mỗi ngày
4. KHÔNG skip phần ôn tập (review)

**Tự tạo thẻ Anki:**
```
Mặt trước: Từ tiếng Anh + ví dụ câu
Mặt sau:   Nghĩa + phiên âm + từ đồng nghĩa

Ví dụ:
Mặt trước: "deadline"
           "We need to meet the deadline by Friday."
Mặt sau:   Hạn chót • /ˈdedlaɪn/
           ≈ due date, cutoff date
```
