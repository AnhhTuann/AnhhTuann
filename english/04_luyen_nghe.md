## 2. 3 Kỹ Thuật Luyện Nghe

### 🔵 Extensive Listening (Nghe rộng)
> Nghe NHIỀU, không cần hiểu 100%

- Chọn nội dung **dễ hơn trình độ 1 bậc**
- Không dừng để tra từ điển
- Mục tiêu: quen với tốc độ, ngữ điệu, âm nối
- **Thực hành:** Nghe BBC 6 Minute English mỗi sáng

### 🟡 Intensive Listening (Nghe sâu)
> Nghe ÍT nhưng hiểu thật kỹ

1. Nghe lần 1 → Hiểu đại ý
2. Nghe lần 2 → Chú ý chi tiết
3. Đọc transcript → So sánh với những gì nghe được
4. Highlight từ/cụm từ mới
5. Nghe lại → Không nhìn transcript

### 🟠 Dictation (Nghe chép)
> Cực kỳ hiệu quả, khó nhưng đáng

- Nghe → Dừng → Viết lại từng câu
- Kiểm tra với transcript
- Cải thiện cả nghe, viết, chính tả và ngữ pháp cùng lúc

## 3. Âm Nối & Phát Âm Giảm (Connected Speech)

Đây là lý do tại sao nghe người thật khó hơn nghe bài học nhiều lần!

### LINKING (Âm nối — phụ âm + nguyên âm nối nhau)
```
"turn it off"  →  /tɜːr·nɪ·tɒf/   (r + i nối)
"not at all"   →  /nɒ·tə·tɔːl/    (t + a nối liền)
"pick it up"   →  /pɪ·kɪ·tʌp/     (k + i nối)
```

### ELISION (Lược âm — bỏ bớt âm)
```
"next day"     →  /neks deɪ/      (bỏ /t/)
"last night"   →  /læs naɪt/      (bỏ /t/)
"you and me"   →  /jə·n·miː/      (bỏ "ou" trong you)
```

### REDUCTION (Giảm âm — nói nhanh, âm yếu đi)
```
"want to"      →  "wanna"
"going to"     →  "gonna"
"have to"      →  "hafta"
"kind of"      →  "kinda"
"a lot of"     →  "a lotta"
"of course"    →  /ə kɔːrs/
```

### ASSIMILATION (Đồng hóa — âm bị ảnh hưởng bởi âm kế bên)
```
"did you"      →  /dɪdʒ u/
"would you"    →  /wʊdʒ u/
"could you"    →  /kʊdʒ u/
"don't you"    →  /doʊntʃ u/
```

## 4. Lịch Luyện Nghe Hàng Ngày

```
SÁNG (10 phút):
└── BBC 6 Minute English → Nghe 1 lần, ghi từ mới

TRƯA (5 phút):
└── Nghe lại + đọc transcript, kiểm tra từ đã ghi

TỐI (10 phút):
├── Shadowing 1 đoạn ngắn (xem file Luyện Nói)
└── Dictation 2–3 câu từ podcast
```
