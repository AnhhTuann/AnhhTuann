## PHẦN 1: ĐỌC (Reading)

### 1. 3 Chiến Lược Đọc

**🔵 Skimming — Đọc lướt (Nắm đại ý)**
- Đọc tiêu đề, heading, câu đầu mỗi đoạn
- Nhìn vào bold text, bullet points, hình ảnh
- Mục tiêu: 1–2 phút cho 1 trang
- *Dùng khi:* Muốn biết bài nói về cái gì trước khi đọc kỹ

**🟡 Scanning — Đọc quét (Tìm thông tin cụ thể)**
- Biết trước cần tìm gì
- Chạy mắt nhanh qua văn bản
- Dừng lại khi thấy keyword
- *Dùng khi:* Tìm số liệu, tên riêng, định nghĩa cụ thể

**🟠 Intensive Reading — Đọc kỹ (Hiểu 100%)**
- Đọc từng câu, hiểu đầy đủ
- Tra từ mới (nhưng đừng tra hết — đoán nghĩa theo ngữ cảnh trước)
- Ghi chú từ/cụm quan trọng vào Anki

### 2. Đọc Theo Ngữ Cảnh (Không Cần Tra Từ Điển)

> **Ví dụ:**
> "The function was **deprecated** in v18, so developers should migrate to the new API."

→ Dù không biết "deprecated", từ ngữ cảnh **suy ra:** đây là tính năng cũ, cần chuyển sang cái mới.

**Các dấu hiệu ngữ cảnh thường gặp:**
```
"X, which means..."        → X được giải thích ngay sau
"X, also known as Y"       → X = Y
"X, such as A, B, C"       → X là một nhóm, A/B/C là ví dụ
"X, as opposed to Y"       → X và Y trái nghĩa nhau
"X; however, Y"            → Y mâu thuẫn hoặc hạn chế X
```

### 3. Cấu Trúc Đoạn Văn Tiếng Anh

```
[Topic Sentence]     → Câu chủ đề (ý chính của đoạn)
[Supporting Details] → Chi tiết hỗ trợ, bằng chứng, ví dụ
[Concluding Sentence]→ Câu kết hoặc chuyển sang ý tiếp
```

**Ví dụ:**
> **[Topic]** React is the most popular JavaScript library for building UIs.
> **[Evidence]** According to the 2024 Stack Overflow survey, 40% of developers use React.
> **[Explanation]** Its component-based architecture makes code reusable and maintainable.
> **[Link]** This explains why companies like Meta, Airbnb, and Netflix continue to use React.

### 4. Tài Liệu Đọc Gợi Ý

| Level | Đọc Gì |
|---|---|
| A2–B1 | VOA Learning English, BBC News Easy |
| B1 | dev.to (bài ngắn), README của GitHub projects |
| B1–B2 | MDN Web Docs, medium.com tech |
| B2+ | React/Node.js official docs, hackernews |

## PHẦN 2: VIẾT (Writing)

### 1. Viết Email Chuyên Nghiệp

**Email xin việc:**
```
Subject: Frontend Developer Application — Nguyen Duc Anh Tuan

Dear Hiring Manager,

I am writing to express my interest in the Frontend Developer 
position at [Company Name]. With [X] years of experience 
building responsive web applications using React and TypeScript,
I am confident in my ability to contribute to your team.

In my recent project, I [specific achievement with numbers].
I am particularly drawn to [Company] because [specific reason].

I would welcome the opportunity to discuss how my skills align 
with your needs. Please find my resume and portfolio attached.

Thank you for your time and consideration.

Best regards,
Nguyen Duc Anh Tuan
```

**Email báo lỗi (Bug Report):**
```
Subject: Bug Report — [Feature Name] not working on Mobile

Hi [Name],

I wanted to flag an issue I found in [feature/component].

Issue:
- The dropdown menu doesn't close when clicking outside on iOS.

Steps to reproduce:
1. Open the app on iPhone (iOS 16+)
2. Click on the user menu dropdown
3. Click anywhere outside the dropdown

Expected: Dropdown closes
Actual:   Dropdown remains open

This is affecting ~15% of our mobile users. I'll investigate 
further, but wanted to give you a heads up.

Best,
Tuan
```

**Email cập nhật tiến độ (Status Update):**
```
Subject: Weekly Progress Update — [Project Name]

Hi team,

Quick update on this week's progress:

✅ Completed:
- Implemented the new login page UI
- Fixed 3 reported bugs (see tickets #123, #124, #125)

🔄 In Progress:
- Working on the dashboard redesign (70% done)

⚠️ Blockers:
- Waiting for design assets from [Name]

On track to deliver by [date].

Best,
Tuan
```

### 2. Viết Đoạn Văn Chuẩn — Mẫu PEEL

```
P — Point (Ý chính):
"React is the most popular JavaScript library for building UIs."

E — Evidence (Bằng chứng):
"According to the 2024 Stack Overflow survey, 40% of developers
use React in their projects."

E — Explanation (Giải thích):
"Its component-based architecture makes code reusable and 
maintainable, reducing development time significantly."

L — Link (Kết nối/Kết luận):
"This explains why companies like Meta, Airbnb, and Netflix 
continue to use React as their primary frontend framework."
```

### 3. Luyện Viết Mỗi Ngày

**Daily Journal (5 phút/ngày):**
> Viết 3–5 câu về ngày hôm nay bằng tiếng Anh.

Gợi ý câu hỏi để trả lời:
```
- What did I do today?
- What was challenging?
- What did I learn?
- What am I grateful for?
- What do I want to improve tomorrow?
```

**Grammarly** — Kiểm tra văn phong khi viết:
- Cài extension trên Chrome
- Dùng khi viết email, comment GitHub, Slack
