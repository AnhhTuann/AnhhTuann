## 🧠 Nguyên Tắc Học Hiệu Quả

### ⚡ 5 Nguyên Tắc Vàng

| # | Nguyên Tắc | Giải Thích |
|---|---|---|
| 1 | **Học mỗi ngày, dù chỉ 15 phút** | Não ghi nhớ qua lặp lại. Nghỉ 3 ngày = mất 30% tiến độ |
| 2 | **Input trước, Output sau** | Nghe + Đọc nhiều trước, rồi mới Nói + Viết |
| 3 | **Học theo ngữ cảnh** | Học từ trong câu, đoạn văn — không học từ đơn lẻ |
| 4 | **Spaced Repetition (Ôn lặp cách quãng)** | Ôn lại sau 1 ngày → 3 ngày → 7 ngày → 21 ngày |
| 5 | **Comprehensible Input (i+1)** | Chọn tài liệu khó hơn trình độ hiện tại 1 bậc |

### 🚫 Những Sai Lầm Cần Tránh

- ❌ Học từ vựng đơn lẻ không có ngữ cảnh
- ❌ Dịch từng từ khi đọc/nghe
- ❌ Chờ "giỏi" rồi mới nói
- ❌ Học ngữ pháp thuần lý thuyết, không luyện tập
- ❌ Học nhiều app cùng lúc, không có hệ thống
- ❌ So sánh bản thân với người khác

### ✅ Thói Quen Của Người Học Giỏi

- ✅ **Immersion:** Đổi ngôn ngữ điện thoại/máy tính sang tiếng Anh
- ✅ **Think in English:** Tập suy nghĩ bằng tiếng Anh (self-talk)
- ✅ **Journal:** Viết nhật ký 3–5 câu mỗi ngày bằng tiếng Anh
- ✅ **Shadowing:** Nghe và nhắc lại ngay lập tức theo người bản ngữ
- ✅ **Review mistakes:** Ghi lại lỗi sai, không mắc lại lần 2

## 📅 Giai Đoạn 1 — Nền Tảng (Tháng 1–2)

**Mục tiêu:** Phát âm chuẩn + 500 từ cơ bản + nắm ngữ pháp A1  
**Level đạt được:** A1 → A2

### 🎯 Tuần 1–2: Phát Âm & Bảng Chữ Cái

- [ ] Học 44 âm vị tiếng Anh (Phonemes) — IPA cơ bản
- [ ] Phân biệt nguyên âm ngắn/dài: `/ɪ/` vs `/iː/`, `/ʊ/` vs `/uː/`
- [ ] Học cách đọc từ điển (ký hiệu phiên âm)
- [ ] Luyện: `th` (`/θ/` vs `/ð/`), `v` vs `w`, `r` vs `l`
- [ ] Tool: **Forvo** (nghe người bản ngữ đọc từ)

### 🎯 Tuần 3–4: 200 Từ Cơ Bản Nhất

Học theo chủ đề:
- **Số đếm:** one, two, three... hundred, thousand
- **Màu sắc:** red, blue, green, yellow, black, white...
- **Thời gian:** today, yesterday, tomorrow, now, soon...
- **Gia đình:** mother, father, brother, sister, friend...
- **Hành động cơ bản:** go, eat, drink, sleep, work, study...

### 🎯 Tuần 5–6: Ngữ Pháp A1 Cốt Lõi

- **To be:** am / is / are
- **Đại từ nhân xưng:** I, you, he, she, it, we, they
- **Câu khẳng định, phủ định, nghi vấn** đơn giản
- **Simple Present Tense** — thì hiện tại đơn
- **There is / There are**

### 🎯 Tuần 7–8: Mở Rộng & Ôn Tập

- Học 300 từ còn lại (tổng 500 từ)
- Ôn ngữ pháp qua bài tập thực hành
- Bắt đầu nghe **podcast A1** (5 phút/ngày)
- Viết 3 câu/ngày về bản thân

### 🎯 Chiến Lược Học Từ Vựng Giai Đoạn 2

Dùng phương pháp **FRAMING** khi gặp từ mới:

```
1. Form (Hình thức): Phát âm + Spelling
2. Meaning (Nghĩa): Nghĩa trong ngữ cảnh này
3. Grammar (Ngữ pháp): Danh từ? Động từ? Tính từ?
4. Collocation (Cụm từ): Đi với từ nào?
5. Example (Ví dụ): Tự đặt 1 câu với từ đó
```

### 1. Ngữ Pháp (Grammar)

#### 📌 CÁC THÌ TRONG TIẾNG ANH

##### Thì Hiện Tại Đơn (Simple Present)
```
CẤU TRÚC:
(+) S + V(s/es)        → She works at Google.
(-) S + don't/doesn't + V  → He doesn't like coffee.
(?) Do/Does + S + V?   → Do you study English?

DÙNG KHI:
✓ Thói quen, hành động lặp lại: "I drink coffee every morning."
✓ Sự thật hiển nhiên: "The sun rises in the east."
✓ Lịch trình cố định: "The train leaves at 8 AM."

SIGNAL WORDS: always, usually, often, sometimes, never,
              every day/week/month, on Mondays...
```

##### Thì Hiện Tại Tiếp Diễn (Present Continuous)
```
CẤU TRÚC:
(+) S + am/is/are + V-ing  → I am studying now.
(-) S + am/is/are + not + V-ing
(?) Am/Is/Are + S + V-ing?

DÙNG KHI:
✓ Đang xảy ra ngay lúc nói: "She is typing an email."
✓ Xung quanh thời điểm hiện tại: "I'm reading a book this week."
✓ Kế hoạch tương lai đã sắp xếp: "We are meeting tomorrow."

⚠️ KHÔNG DÙNG V-ING với: know, like, love, hate, want, need,
   believe, understand, remember, forget
```

##### Thì Quá Khứ Đơn (Simple Past)
```
CẤU TRÚC:
(+) S + V2/V-ed           → He worked yesterday.
(-) S + didn't + V(inf)   → She didn't come.
(?) Did + S + V(inf)?     → Did you see it?

ĐỘNG TỪ BẤT QUY TẮC QUAN TRỌNG:
go → went       come → came      see → saw
have → had      do → did         make → made
get → got       give → gave      take → took
know → knew     think → thought  say → said
find → found    leave → left     feel → felt
become → became begin → began    buy → bought

SIGNAL WORDS: yesterday, last week/month/year,
              ago, in 2020, when I was a child...
```

##### Thì Hiện Tại Hoàn Thành (Present Perfect)
```
CẤU TRÚC:
(+) S + have/has + V3/V-ed  → I have finished my work.
(-) S + haven't/hasn't + V3
(?) Have/Has + S + V3?

DÙNG KHI:
✓ Hành động xảy ra và ảnh hưởng đến hiện tại:
  "I have lost my keys." (chưa tìm được)
✓ Kinh nghiệm trong cuộc đời: "I have been to Japan."
✓ Hành động vừa xong: "She has just sent the email."
✓ Hành động từ quá khứ đến nay: "I have worked here for 5 years."

SIGNAL WORDS: just, already, yet, ever, never, recently,
              lately, for, since, so far, up to now...

⚠️ So sánh:
"I ate pizza." → Quá khứ cụ thể (không liên quan hiện tại)
"I have eaten pizza." → Kinh nghiệm đã từng ăn (liên quan hiện tại)
```

##### Thì Tương Lai (Future)
```
WILL (Quyết định tức thì, dự đoán, lời hứa):
"I will help you." / "It will rain tomorrow."

BE GOING TO (Kế hoạch, dự định, bằng chứng rõ ràng):
"I am going to study abroad next year."
"Look at those clouds — it's going to rain!"

PRESENT CONTINUOUS (Sắp xếp cụ thể, xác nhận):
"I'm meeting John at 3 PM tomorrow."

PRESENT SIMPLE (Lịch trình cố định):
"The flight departs at 6 AM."
```

#### 📌 CÁC LOẠI CÂU

##### Câu Điều Kiện (Conditionals)
```
TYPE 0 — Sự thật hiển nhiên:
If + Simple Present, Simple Present
"If you heat water to 100°C, it boils."

TYPE 1 — Điều kiện có thể xảy ra (tương lai):
If + Simple Present, will + V(inf)
"If it rains, I will stay home."

TYPE 2 — Điều kiện giả định (hiện tại/tương lai):
If + Simple Past, would + V(inf)
"If I had more time, I would learn guitar."

TYPE 3 — Điều kiện trong quá khứ (không thể thay đổi):
If + Past Perfect, would have + V3
"If I had studied harder, I would have passed the exam."

MIXED CONDITIONAL:
If + Past Perfect, would + V(inf)
"If I had chosen Computer Science, I would be a developer now."
```

##### Câu Bị Động (Passive Voice)
```
CẤU TRÚC: Object + be + V3 (+ by + Agent)

CHUYỂN ĐỔI:
Active:  "The team fixed the bug."
Passive: "The bug was fixed (by the team)."

CÁC THÌ BỊ ĐỘNG:
Simple Present:    The code is reviewed daily.
Simple Past:       The bug was fixed yesterday.
Present Perfect:   The feature has been deployed.
Simple Future:     The app will be launched next week.
Present Continuous: The issue is being investigated.

DÙNG KHI:
✓ Không biết / không cần nêu chủ thể
✓ Nhấn mạnh vào đối tượng bị tác động
✓ Văn phong trang trọng, khoa học
```

##### Câu Quan Hệ (Relative Clauses)
```
WHO    → người:   "The developer who built this app is amazing."
WHICH  → vật:    "The tool which I use is VSCode."
THAT   → người/vật: "The project that we finished was successful."
WHERE  → nơi chốn: "This is the office where I work."
WHEN   → thời gian: "I remember the day when I got my first job."
WHOSE  → sở hữu:   "The colleague whose code I reviewed is talented."

DEFINING vs NON-DEFINING:
Defining (không có dấu phẩy): "The car that I bought is red." 
→ Xác định cụ thể chiếc xe nào

Non-defining (có dấu phẩy): "My car, which is red, needs repair."
→ Cung cấp thêm thông tin về chiếc xe đã biết
```

#### 📌 MODAL VERBS

| Modal | Cách dùng chính | Ví dụ |
|---|---|---|
| **can** | Khả năng hiện tại | "I can code in React." |
| **could** | Khả năng quá khứ / đề nghị lịch sự | "Could you help me?" |
| **will** | Tương lai / quyết định | "I will fix this bug." |
| **would** | Điều kiện / lịch sự | "Would you like some help?" |
| **should** | Lời khuyên | "You should refactor this code." |
| **must** | Bắt buộc / kết luận chắc chắn | "You must submit by Friday." |
| **have to** | Bắt buộc từ bên ngoài | "I have to attend the meeting." |
| **may** | Khả năng / xin phép (trang trọng) | "May I ask a question?" |
| **might** | Khả năng nhỏ hơn may | "It might rain later." |
| **need to** | Cần thiết | "We need to deploy this now." |

#### 📌 GIỚI TỪ (Prepositions)

```
THỜI GIAN:
at  → giờ cụ thể:      at 9 AM, at noon, at midnight
on  → ngày:            on Monday, on July 22, on my birthday
in  → tháng/năm/mùa:  in July, in 2024, in summer, in the morning

NƠI CHỐN:
at  → điểm cụ thể:     at school, at the office, at home
on  → bề mặt:          on the table, on the screen, on the wall
in  → bên trong:       in the room, in Vietnam, in the browser

KHÁC:
for   → thời gian kéo dài: "I've worked here for 3 years."
since → từ mốc thời gian:  "I've been coding since 2019."
by    → hạn chót / tác nhân: "Submit by Friday." / "Built by Google."
with  → cùng / dụng cụ:    "I work with React." / "Write with a pen."
about → về chủ đề:         "Tell me about your project."
```

| Cấp Độ | Tốc Độ | Tài Nguyên Gợi Ý |
|---|---|---|
| A1–A2 | Rất chậm | VOA Learning English (Everyday), ESLPod |
| A2–B1 | Chậm vừa | TED-Ed, BBC Learning English |
| B1–B2 | Tự nhiên | TED Talks, Podcasts IT, YouTube |
| B2+ | Bản ngữ | Netflix (EN sub), Podcasts kỹ thuật |

#### 📌 KỸ THUẬT LUYỆN NGHE

**Extensive Listening (Nghe rộng):**
- Nghe nhiều nội dung dễ hơn trình độ 1 bậc
- Không dừng để tra từ điển
- Mục tiêu: Quen với tốc độ, ngữ điệu, âm nối

**Intensive Listening (Nghe sâu):**
1. Nghe lần 1 — Hiểu đại ý
2. Nghe lần 2 — Chú ý chi tiết
3. Đọc transcript — So sánh với những gì nghe được
4. Highlight từ/cụm từ mới
5. Nghe lại — Lần này không cần nhìn transcript

**Dictation (Nghe chép):**
- Nghe → Dừng → Viết lại từng câu
- Kiểm tra với transcript
- Rất hiệu quả để cải thiện spelling và grammar

#### 📌 ÂM NỐI & PHÁT ÂM GIẢM (Connected Speech)

```
LINKING (Âm nối):
"turn it off" → /tɜːr nɪ tɒf/  (r + i nối)
"not at all"  → /nɒ tə tɔːl/  (t + a + t + a nối)

ELISION (Lược âm):
"next day"    → /neks deɪ/    (bỏ /t/)
"last night"  → /læs naɪt/   (bỏ /t/)
"friendship"  → /frens ʃɪp/  (bỏ /d/)

REDUCTION (Giảm âm):
"want to"     → "wanna"
"going to"    → "gonna"
"have to"     → "hafta"
"of course"   → /əv kɔːrs/ → /ə kɔːrs/

ASSIMILATION (Đồng hóa):
"did you"     → /dɪdʒ u/
"would you"   → /wʊdʒ u/
"could you"   → /kʊdʒ u/
```

### 4. Nói (Speaking)

#### 📌 CÁCH PHÁT ÂM TỪNG ÂM KHÓ

```
TH SOUNDS:
/θ/ (không rung): think, three, through, method, math
  → Đặt đầu lưỡi giữa hai răng, thổi hơi ra

/ð/ (rung): this, that, the, mother, brother, weather
  → Giống /θ/ nhưng có tiếng thanh quản

V vs W:
/v/: very, video, value, have, live
  → Môi dưới chạm răng trên nhẹ, thổi hơi

/w/: what, where, work, water, word
  → Tròn môi như thổi nến, không chạm răng

R vs L:
/r/: right, read, great, program, arrive
  → Lưỡi cong lên, không chạm vòm miệng

/l/: left, long, play, call, feel
  → Đầu lưỡi chạm vòm miệng phía sau răng trên
```

#### 📌 CÁC CẤU TRÚC NÓI QUAN TRỌNG

**Giới thiệu bản thân:**
```
"Hi, my name is Tuan. I'm a Frontend Developer with [X] years of experience.
I specialize in React and I'm passionate about building clean, performant UIs.
Currently I'm working as a freelancer focusing on e-commerce and landing pages."
```

**Ý kiến & Quan điểm:**
```
Đồng ý:      "I totally agree with that."
              "That's a great point."
              "Exactly! / Absolutely!"

Không đồng ý: "I see your point, but I think..."
              "Actually, I'd look at it differently."
              "With all due respect, I disagree because..."

Không chắc:   "I'm not 100% sure, but..."
              "I think... but I could be wrong."
              "It depends on the situation."
```

**Diễn giải & Giải thích:**
```
"What I mean is..."
"In other words..."
"To put it simply..."
"Let me give you an example..."
"The reason is that..."
"This is important because..."
```

**Hỏi lại khi không hiểu:**
```
"Could you repeat that, please?"
"Sorry, I didn't catch that."
"Could you speak a bit more slowly?"
"What do you mean by [word]?"
"Could you clarify that?"
```

#### 📌 LUYỆN NÓI TỰ PHÁT (Fluency Drills)

**Bài tập 1: Describe the photo** (2 phút)
> Mỗi ngày chọn 1 ảnh ngẫu nhiên, nói 2 phút về ảnh đó.
> "In this picture, I can see... It looks like... I think the person is..."

**Bài tập 2: Monologue topics** (1–2 phút mỗi chủ đề)
- Describe your morning routine
- Talk about your favorite movie and why
- Explain what Frontend development is to a non-tech person
- Describe the last project you worked on
- Talk about a challenge you overcame

**Bài tập 3: Think in English** (Cả ngày)
> Khi làm việc, ăn, đi đường — hãy đặt câu hỏi trong đầu bằng tiếng Anh:
> "What am I doing right now?" → "I'm reviewing this pull request."
> "Why is this component re-rendering?" → "Because the state changed."

### 5. Đọc (Reading)

#### 📌 CHIẾN LƯỢC ĐỌC

**Skimming (Đọc lướt) — Nắm đại ý:**
- Đọc tiêu đề, heading, câu đầu mỗi đoạn
- Nhìn vào bold text, bullet points
- Mục tiêu: 1–2 phút cho 1 trang

**Scanning (Đọc quét) — Tìm thông tin cụ thể:**
- Biết trước cần tìm gì
- Chạy mắt nhanh qua văn bản
- Dừng lại khi thấy keyword

**Intensive Reading (Đọc kỹ):**
- Đọc từng câu, hiểu đầy đủ
- Tra từ mới (nhưng đừng tra hết mọi từ)
- Ghi chú từ/cụm quan trọng

**Đọc theo ngữ cảnh (không cần tra từ điển):**
> "The function was deprecated in v18, so developers should migrate to the new API."
> → Dù không biết "deprecated", từ ngữ cảnh hiểu: tính năng cũ, nên chuyển sang mới

#### 📌 CẤU TRÚC BÀI ĐỌC TIẾNG ANH

```
PARAGRAPH STRUCTURE:
[Topic Sentence]    → Câu chủ đề (ý chính của đoạn)
[Supporting Details] → Các chi tiết hỗ trợ, bằng chứng, ví dụ
[Concluding Sentence] → Câu kết, hoặc chuyển ý
```

#### 📌 VIẾT EMAIL CHUYÊN NGHIỆP

**Email xin việc:**
```
Subject: Frontend Developer Application — Nguyen Duc Anh Tuan

Dear Hiring Manager,

I am writing to express my interest in the Frontend Developer 
position at [Company Name]. With [X] years of experience 
building responsive web applications using React and TypeScript,
I am confident in my ability to contribute to your team.

In my recent project, I [specific achievement with numbers].
I am particularly drawn to [Company] because [specific reason].

I would welcome the opportunity to discuss how my skills align 
with your needs. Please find my resume and portfolio attached.

Thank you for your time and consideration.

Best regards,
Nguyen Duc Anh Tuan
```

**Email report lỗi:**
```
Subject: Bug Report — [Feature Name] not working on Mobile

Hi [Name],

I wanted to flag an issue I found in [feature/component].

Issue:
- The dropdown menu doesn't close when clicking outside on iOS.

Steps to reproduce:
1. Open the app on iPhone (iOS 16+)
2. Click on the user menu dropdown
3. Click anywhere outside the dropdown

Expected: Dropdown closes
Actual: Dropdown remains open

This is affecting ~15% of our mobile users. I'll investigate 
further, but wanted to give you a heads up.

Best,
Tuan
```

#### 📌 VIẾT PARAGRAPH CHUẨN

**Mẫu PEEL:**
```
P — Point (Ý chính):
"React is the most popular JavaScript library for building UIs."

E — Evidence (Bằng chứng):
"According to the 2024 Stack Overflow survey, 40% of developers
use React in their projects."

E — Explanation (Giải thích):
"Its component-based architecture makes code reusable and 
maintainable, reducing development time significantly."

L — Link (Kết nối/Kết luận):
"This explains why companies like Meta, Airbnb, and Netflix 
continue to use React as their primary frontend framework."
```

## 🎯 Tiếng Anh Chuyên Ngành IT

### 📌 KỸ THUẬT GIẢI THÍCH CODE BẰNG TIẾNG ANH

**Mô tả function:**
```
"This function takes [input] as a parameter and returns [output].
It first checks if [condition], then [does something].
If the condition is not met, it [does something else]."

Ví dụ:
"This function takes a user ID as a parameter and returns 
a promise that resolves to the user object. It first checks 
if the ID is valid, then fetches the data from the API.
If the ID is invalid, it throws an error."
```

**Giải thích bug:**
```
"I found a bug in the [component/function]. 
When [condition], the app [unexpected behavior].
The root cause is [explanation].
My fix is to [solution]."
```

### 📌 TỪNG BƯỚC PHỎNG VẤN TECHNICAL

**Opening:**
> "Let me think about this for a moment..."
> "I'll start by clarifying the requirements..."
> "My initial approach would be..."

**Trong quá trình giải:**
> "I'm thinking of using X because..."
> "This has a time complexity of O(n)..."
> "An edge case I need to handle is..."
> "I could optimize this by..."

**Kết thúc:**
> "To summarize my approach..."
> "The trade-off of this solution is..."
> "Given more time, I would also..."

### 📌 BEHAVIORAL QUESTIONS (STAR METHOD)

```
S — Situation: "In my previous project, we had..."
T — Task:      "My responsibility was to..."
A — Action:    "I decided to... / I took the approach of..."
R — Result:    "As a result, we achieved... / The outcome was..."
```

**Câu hỏi thường gặp & Cách trả lời:**

| Câu Hỏi | Điểm Cần Nêu |
|---|---|
| "Tell me about yourself." | Background → Skills → Goals |
| "Why do you want this job?" | Company research + Personal fit |
| "What's your greatest strength?" | Specific skill + Example |
| "What's your weakness?" | Real weakness + How you're improving |
| "Describe a challenging project." | STAR method |
| "Where do you see yourself in 5 years?" | Growth + Commitment |
